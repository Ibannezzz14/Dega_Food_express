# Ajouter de nouvelles photos

Ce dossier sert uniquement de boîte de dépôt avant intégration au site.

1. Déposer la photo dans la bonne catégorie de `A-INTEGRER/`.
2. Indiquer si possible le nom du plat dans le nom du fichier.
3. Après validation et optimisation, la photo publiée sera rangée dans
   `public/images/menu/`.
4. L’original sera conservé dans `assets/source-images/raw/`.

Les images déjà visibles sur le site ne sont pas copiées ici : elles se
trouvent dans `public/images/`. Les sources et anciennes images sont archivées
dans `assets/source-images/`. Cette séparation évite les doublons.
